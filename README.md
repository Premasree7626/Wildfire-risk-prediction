# Wildfire-risk-prediction
 Description
This project focuses on predicting wildfire risk using machine learning models based on weather and satellite data. It aims to identify high-risk zones and support early warning systems.

## 🛠️ Tech Stack
- Python  
- Pandas, NumPy  
- Scikit-learn  
- LightGBM (LGBM)  
- XGBoost  
- Matplotlib / Seaborn  

## ⚙️ Workflow
- Data collection from weather and satellite sources  
- Data preprocessing and cleaning  
- Exploratory Data Analysis (EDA)  
- Model building using LGBM and XGBoost  
- Performance comparison of models  

## 📊 Results
- ✅ LGBM Accuracy: 91.15%  
- ✅ XGBoost Accuracy: 87.89%
  
## 💡 Conclusion
LGBM outperformed XGBoost in terms of accuracy and real-time prediction capability. The model can effectively identify high-risk wildfire zones, helping in early warning and disaster management.
